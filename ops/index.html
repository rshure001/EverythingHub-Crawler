Recovery sequence

1. Restore database responsiveness before increasing crawler concurrency.

2. Confirm a simple database query succeeds.

3. Test public search with several unrelated queries and verify real result counts.

4. Confirm crawler queue claims, writes, and scheduled runs.

5. Only then tune throughput using measured production capacity.
